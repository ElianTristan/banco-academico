# Cuentas de prueba

Estas identidades son datos ficticios. Créelas desde **Administración → Usuarios → Agregar Usuario** después de iniciar sesión con una cuenta administradora. El alta existente crea una contraseña temporal y exige cambiarla en el primer acceso.

| Tipo | Nombre | Correo de ejemplo | Identificador |
| --- | --- | --- | --- |
| Alumno | Ana Demo | ana.alumna.demo@example.com | DEMO-ALU-001 |
| Alumno | Luis Prueba | luis.alumno.demo@example.com | DEMO-ALU-002 |
| Docente | Docente Demo | docente.demo@example.com | DEMO-DOC-001 |

`example.com` es un dominio reservado para ejemplos; cámbialo por correos de cuentas controladas si necesitas probar login y avisos. Para probar notificaciones por grupo, inscribe primero un alumno de prueba a un grupo y asigna un docente de prueba a ese mismo grupo. Para probar el envío institucional, usa una cuenta administradora y el destinatario “Todos los alumnos”.
